# Word 桌宠 (Word Desktop Pet)

一只会在你打开 Word 后自动出现的桌面宠物：

1. **独立启动**：单独运行本程序，后台自动检测 Word（WINWORD.EXE），一旦检测到 Word 打开，桌宠就会从屏幕底部弹出来。
2. **字节统计**：记录本次 Word 会话中**录入**的字节数。**只统计你新输入的内容，不包括文档原有文字**：
   - 输入 / 粘贴 → 计数累加；
   - 删除**本次录入**的内容 → 计数相应扣减；
   - 删除**文档原有内容**（打开前就存在的）→ 计数不受影响；
   - 切换文档或重新打开 Word 会重新开始计数。
3. **点击对话**：左键点击桌宠弹出对话框，每次点击切换一句不同台词；台词标题和内容都可直接编辑并自动保存到 `config.json`（预留了充分的文本空间，想好内容后直接改文字即可）。对话框顶部**实时显示本次输入的字节数**。
4. **拖拽动作**：
   - 按住拖动 → 播放"拖动"动画；
   - 靠近 **Word 窗口上边缘**松手（窗口未最大化时）→ 桌宠挂在窗口上边缘，并**跟随窗口移动**；
   - 挂靠中 Word 窗口**最大化 / 最小化 / 关闭**时桌宠自动脱落；最大化的窗口不可挂靠；
   - 靠近**屏幕底部**松手 → 停在底部；
   - 在其他位置松手 → 掉落到桌面底部，**落地即停，无回弹**；
   - 右键 → 菜单（打开对话框 / 回到底部 / 退出）。

## 使用方法

```bash
# 1. 安装依赖（需要 Python 3.8+）
pip install -r requirements.txt

# 2. 启动（双击 run.bat 也可以）
python word_pet.py

# 3. 打开/切换到 Word，桌宠会自动弹出
```

## 放入你的桌宠 GIF

把 GIF 文件放到 `assets/pet/` 目录，按状态命名：

| 文件名 | 状态 |
|---|---|
| `idle.gif` | 待机（默认循环动画） |
| `drag.gif` | 被拖动时 |
| `hang.gif` | 挂在屏幕边缘时 |
| `fall.gif` | 松手下落时 |

- 没放 GIF 时会显示内置的占位小圆宠，功能不受影响。
- 想换文件名、路径或调整尺寸，改 `config.json` 里的 `pet.gifs` 和 `pet.size`（宽, 高 像素）。

## 字节统计说明

- **计数单位**由 `config.json` 的 `counter.mode` 决定，改完重启程序生效：

| mode | 单位 | 1 个汉字 | 1 个英文字母 |
|---|---|---|---|
| `chars`（默认） | 字（字符数） | 1 | 1 |
| `utf8` | 字节(UTF-8) | 3 | 1 |
| `gbk` | 字节(GBK) | 2 | 1 |

- 通过 Word COM 接口读取当前活动文档内容，按所选单位统计：
  - 检测到文档时记录**基线**（原有内容大小）；
  - 内容**增加**多少字节，本次录入计数就加多少（中文输入法上屏、粘贴都算）；
  - 内容**减少**时，只有能归属为"本次录入"的部分才会被扣减，**删除原文不影响计数**；
  - 也就是说：打开旧文档、先删一堆旧文字再写新内容，计数只反映新写的部分。
- 切换到另一份文档时，以该文档当时的内容为新基线、计数清零（统计当前文档会话）。
- 需要 `pywin32` 才能统计；未安装时桌宠仍能显示，但对话框会提示无法统计。
- Word 刚打开的一瞬间可能连不上 COM（Word 尚未在系统注册），此时桌宠照常出现，对话框会提示"等待连接"，点击一次其他窗口切换焦点后即可自动开始统计。
- **中文/英文双通道计数**（无需检测输入法状态，按上屏字符类型自动分流）：
  - **中文通道**（汉字/全角字符）：**即时结算**——汉字上屏立刻计入，不受拼音组字干扰（拼音属于英文通道）；
  - **英文通道**（字母/半角字符）：**防抖结算**——英文内容稳定 1.2 秒才计入，输入法组字的拼音中间态会被自动跳过；
  - 两通道完全独立：中文输入不会重置英文的防抖计时；总计数 = 中文 + 英文（对话框中也会分项显示）；
  - 用英文输入法打字时全部走英文通道（即防抖方案），行为不变。
- 每约 0.5 秒轮询一次（大文档做了优化，内容不变时不会重复读取全文）。

## 常见问题

- **桌宠不出现**：确认已安装依赖且 Word 是桌面版（WPS 不支持 COM 统计）；右下角无窗口时可看任务管理器中 `python.exe` 是否在运行。
- **对话框位置挡住内容**：对话框总是出现在桌宠旁边，拖动桌宠即可。
- **打包成 exe**（如需分发）：`pip install pyinstaller` 后执行
  `pyinstaller --onefile --windowed --name word_pet word_pet.py`

## 文件结构

```
word-pet/
├── word_pet.py       # 主程序（单文件，可直接运行）
├── config.json       # 配置：GIF 路径、尺寸、台词（运行中可编辑保存）
├── requirements.txt  # 依赖
├── run.bat           # Windows 一键启动
└── assets/pet/       # 放 GIF 动画（idle/drag/hang/fall）
```
